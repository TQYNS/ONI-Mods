# ONI-Mods

《缺氧》Mod 源码仓库。

## 项目

- `EventFramework`：事件框架，提供事件契约、运行时、分发与版本管理、YAML 事件、UI、音频、存档、历史与奖励。
- `MoreFoodProject`：「逐鹿星河」内容 Mod，包含食物、饮品、Buff、建筑、图鉴、星图贸易/战斗/探索、事件、UI、兼容与修复。
